## Техническое задание: Сервис точечного Inpainting-редактирования по маске

### 1. Концепция и цель проекта

Создание легковесного веб-сервиса с интерфейсом в светлой теме для локального или серверного запуска. Сервис предназначен исключительно для одной задачи: загрузить изображение, точно выделить область (лассо, прямоугольник, кисть), описать текстом изменение и отправить запрос к API нейросетей (ChatGPT Image или Gemini Nano Banana) — напрямую или через сторонние API-роутеры/прокси. В сервисе намеренно отсутствуют лишние инструменты рисования (карандаши, палитры цветов, фильтры).   

### 2. Стек технологий и архитектура

- **Frontend:** Vue 3 (или React) + Vite, TypeScript, Tailwind CSS (светлая палитра: `#F8FAFC`, `#FFFFFF`, `#E2E8F0`, акцент `#2563EB`).
- **Canvas движок:** `Konva.js` (`vue-konva` / `react-konva`) или чистый HTML5 Canvas с поддержкой масштабирования и панорамирования (Zoom & Pan).
- **Backend:** FastAPI (Python) или Express.js (Node.js).
  - *Роль бэкенда в MVP:* Проксирование запросов к нейросетям (чтобы избежать проблем с CORS), адаптация формата маски под выбранного провайдера (OpenAI / Gemini / Router) и локальное сохранение временных файлов при необходимости.   

### 3. Функциональные требования: Фаза 1 (MVP)

#### 3.1. Рабочая область (Холст)

- **Загрузка изображения:** Drag-and-drop на экран или кнопка «Загрузить» (поддержка PNG, JPG, WebP).   
- **Навигация:** Масштабирование колесом мыши (Zoom in/out) и панорамирование зажатием пробела/средней кнопки мыши (Pan).
- **История действий:**
  - **Undo (`Ctrl + Z`):** отмена последнего шага выделения или отмена последней генерации (возврат предыдущей версии изображения).
  - **Redo (`Ctrl + Y`):** повтор отмененного действия.
  - Глубина стека: минимум 20 состояний.
- **Экспорт:** Кнопка «Скачать результат» — сохраняет итоговое изображение в формате PNG в папку «Загрузки» браузера с исходным разрешением.

#### 3.2. Набор инструментов выделения

- Никаких цветовых кистей и палитр. Доступны только 3 режима формирования маски:   
  1. **Прямоугольное выделение (Rectangle):** выделение рамкой нужной области.   
  2. **Кисть выделения (Mask Brush):** закрашивание области полупрозрачным маркером (настройка только диаметра кисти ползунком `1–100px`).   
  3. **Лассо (Lasso):** свободное ручное обведение контура от руки или точками (полигональное лассо) с автоматическим замыканием контура.
- **Действия с маской:**
  - Кнопка «Очистить маску» (сброс текущего выделения).
  - Кнопка «Инвертировать маску» (опционально, для изменения всего кроме выбранного).   

#### 3.3. Панель ввода и настроек генерации

- **Поле промпта:** Многострочное текстовое поле с описанием желаемого изменения внутри выделенной зоны.   
- **Выбор провайдера:** Переключатель (Select):
  - *ChatGPT Image*
  - *Gemini Nano Banana*  
  - *Пользовательский API-роутер* (любой совместимый с OpenAI или Gemini шлюз: OpenRouter, ProxyAPI, Vsegpt и др.).
- **Конфигурация подключения (в MVP хранится в `localStorage`):**
  - `API Key` (скрытое поле с возможностью показать/скрыть).
  - `Base URL` (по умолчанию официальный адрес провайдера, с возможностью заменить на URL любого прокси/роутера, например: `[https://api.proxyapi.ru/v1](https://api.proxyapi.ru/v1)` или `[https://openrouter.ai/api/v1](https://openrouter.ai/api/v1)`).
  - `Model Name` (например, `dall-e-2`, `gemini-2.5-flash-image`, `nano-banana-pro` или кастомная строка для роутера).   
- **Кнопка запуска «Применить изменения»:** При клике блокирует интерфейс и отображает аккуратный индикатор загрузки/спиннер.

### 4. Интеграция API и подготовка данных (Бэкенд-пайплайн)

В зависимости от выбранного провайдера бэкенд формирует запрос по соответствующей спецификации:

#### Вариант А: OpenAI / Роутеры с OpenAI-совместимым API

- **Эндпоинт:** `POST /v1/images/edits` (или адрес роутера).
- **Формат:** `multipart/form-data`.
- **Тело запроса:**
  - `image`: Исходное изображение в формате PNG (альфа-канал прозрачности для стертых участков, либо отдельная маска).   
  - `mask`: Бинарная черно-белая маска в формате PNG (где закрашенная область — прозрачная или белая в зависимости от эндпоинта).
  - `prompt`: Текст пользователя.   
  - `model`: Имя модели.

#### Вариант Б: Gemini Nano Banana / Google AI Studio   

- **Эндпоинт:** `POST [https://generativelanguage.googleapis.com/v1beta/models/](https://generativelanguage.googleapis.com/v1beta/models/){model}:generateContent` (или через Google GenAI SDK).
- **Формат:** `application/json`.
- **Специфика:** Мультимодальный запрос передает исходное изображение (base64 inline_data), маску разметки и текстовую инструкцию (системный промпт: *"Apply the modification specified in the prompt only within the indicated mask boundaries, keeping the remaining background completely identical"*).   

### 5. Требования к UI/UX (Дизайн)

- **Тема:** Строго светлая (чистый минимализм, отсутствие визуального мусора, тонкие границы `#E5E7EB`, мягкие тени `shadow-sm`).   
- **Компоновка экрана (Single-Screen layout):**
  - **Верхняя панель (Header):** Логотип/название, кнопки Undo / Redo, кнопка «Очистить всё», кнопка «Скачать результат».
  - **Центральная часть:** Большой масштабируемый холст (Canvas) со светлым фоном и регулярной серой точечной сеткой (*dot grid pattern*) для наглядной ориентации в пространстве при панорамировании и зуме
  - **Плавающая панель инструментов (слева или сверху холста):** Иконки режимов (Прямоугольник, Лассо, Кисть, Ластик маски, Ползунок размера кисти).   
  - **Правая боковая панель (Панель генерации):**
    - Селектор провайдера и модели.
    - Поле для Base URL и API Key (с кнопкой быстрого сохранения/сброса).
    - Текстовая область для промпта.   
    - Кнопка «Сгенерировать» (яркая, акцентная).
    - Блок вывода ошибок API (если неверный ключ, кончился баланс или неверный URL).

### 6. Дорожная карта: Фаза 2 (Многопользовательский режим)

Разрабатывается после проверки работоспособности базового редактирования:

- **Авторизация:** Простая регистрация (Login + Password) без отправки подтверждений на почту. Хэширование паролей через `bcrypt`, выдача JWT-токенов.
- **База данных:** SQLite или PostgreSQL (простая схема: `Users`, `UserSettings`).
- **Профиль и персональные настройки:**
  - У каждого пользователя в БД сохраняется свой защищенный пул API-ключей, дефолтных Base URL и избранных моделей.
  - Возможность переключаться между своими пресетами (например, пресет «Nano Banana через Router» / пресет «ChatGPT прямой ключ»).
  - Личная история последних 10–20 генераций пользователя (хранение на сервере или в локальном кеше).
